Privacy policy

PinTop displays the window you choose. Its window content stays on your Mac.

Updated October 26, 2026

Window content

PinTop uses the macOS system picker and ScreenCaptureKit to display a live, floating copy of a window you explicitly select. Frames are processed locally in memory. PinTop does not capture audio, record video to disk, upload window images, or forward keyboard and mouse input to other apps. Closing a copy, unpinning, or quitting stops the relevant capture.

Accounts, preferences, and analytics

PinTop does not require a separate account and has no analytics or advertising service. Local app preferences, such as the shortcut and login setting, remain on your Mac. The global shortcut uses system hotkey registration; it does not monitor general typing.

Purchases

Apple processes in-app purchases and subscriptions through StoreKit and the App Store. PinTop checks Apple-verified purchase status to unlock features. PinTop does not receive your payment-card details. Apple handles its services under its own privacy policy.

Support you choose to send

Support uses GitHub Issues. Information you voluntarily include in an issue, such as text or an attachment, is sent to GitHub and is publicly visible. The developer can read it to respond. Do not submit sensitive information. You control what you send; use GitHub to edit or remove your contributions, subject to GitHub’s rules.

This website

This static site adds no analytics, advertising, third-party scripts, or tracking cookies. An explicit language choice is stored locally in your browser. When hosted on GitHub Pages, GitHub logs visitors’ IP addresses for security purposes. GitHub handles hosting and issue data under its privacy statement.

Questions and changes

For a question about this policy or information you submitted, use the support link below without posting sensitive details. This page will show an updated date when the policy changes.

隐私政策

PinTop 显示你选中的窗口。窗口画面留在你的 Mac 上。

更新日期：2026 年 10 月 26 日

窗口内容

PinTop 通过 macOS 系统选择器和 ScreenCaptureKit，显示你明确选中的窗口实时副本。画面帧在本机内存中处理。PinTop 不捕获音频、不将视频录制到磁盘、不上传窗口画面，也不向其他应用转发键盘或鼠标输入。关闭副本、取消置顶或退出应用会停止相应捕获。

账号、偏好与分析

PinTop 不要求单独注册账号，不接入分析或广告服务。快捷键、登录时启动等应用偏好保存在你的 Mac 上。全局快捷键使用系统快捷键注册，不监控日常键盘输入。

购买

Apple 通过 StoreKit 和 App Store 处理应用内购买与订阅。PinTop 检查经 Apple 验证的购买状态以解锁功能，不会收到你的银行卡信息。Apple 按其自身隐私政策处理相关服务。

你主动提交的支持内容

支持通过 GitHub Issues 提供。你主动提交的问题文字、附件等信息会发送给 GitHub，并公开显示。开发者可阅读这些内容并回复。请勿提交敏感信息。提交内容由你选择；可按 GitHub 规则编辑或删除自己的内容。

本网站

本站是纯静态网站，不添加分析、广告、第三方脚本或跟踪 Cookie。你明确选择的语言保存在当前浏览器本地。网站托管于 GitHub Pages 后，GitHub 会出于安全目的记录访问者 IP 地址。托管和 Issues 数据由 GitHub 按其隐私声明处理。

问题与更新

如对本政策或已提交的信息有疑问，请通过下方支持入口联系，不要公开敏感细节。政策变更时，本页会更新日期。

隱私權政策

PinTop 顯示你選取的視窗。視窗畫面留在你的 Mac 上。

更新日期：2026 年 10 月 26 日

視窗內容

PinTop 透過 macOS 系統選擇器與 ScreenCaptureKit，顯示你明確選取的視窗即時副本。畫面影格在本機記憶體中處理。PinTop 不擷取音訊、不將影片錄製至磁碟、不上傳視窗畫面，也不向其他 App 轉送鍵盤或滑鼠輸入。關閉副本、取消置頂或結束 App 會停止對應擷取。

帳號、偏好與分析

PinTop 不要求獨立註冊帳號，不使用分析或廣告服務。快捷鍵、登入時啟動等 App 偏好保存在你的 Mac 上。全域快捷鍵使用系統快捷鍵註冊，不監控日常鍵盤輸入。

購買

Apple 透過 StoreKit 與 App Store 處理 App 內購買與訂閱。PinTop 檢查經 Apple 驗證的購買狀態以解鎖功能，不會收到你的信用卡資訊。Apple 按其自身隱私權政策處理相關服務。

你主動提交的支援內容

支援透過 GitHub Issues 提供。你主動提交的問題文字、附件等資訊會傳送給 GitHub，並公開顯示。開發者可閱讀這些內容並回覆。請勿提交敏感資訊。提交內容由你選擇；可按 GitHub 規則編輯或刪除自己的內容。

本網站

本站是純靜態網站，不加入分析、廣告、第三方指令碼或追蹤 Cookie。你明確選擇的語言儲存在目前瀏覽器本機。網站託管於 GitHub Pages 後，GitHub 會基於安全目的記錄訪客 IP 位址。託管與 Issues 資料由 GitHub 按其隱私權聲明處理。
